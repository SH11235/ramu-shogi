# 駒画像

[sunfish-shogi/shogi-images](https://github.com/sunfish-shogi/shogi-images) の `hitomoji_wood`（CC0 1.0 Universal）を使っています。

成り駒（`black_dragon` / `black_horse` / `black_prom_silver` / `black_prom_knight` / `black_prom_lance` / `black_prom_pawn`）は、実物の駒に合わせて文字を黒から赤に塗り替えています（元の配布物の木目セットには赤い成り駒が無いため）。形と木目は元のままです。
